## Descripción

Proyecto Login es un sistema de registro e inicio de sesión desarrollado como parte del TP3.

Permite crear cuentas, iniciar sesión y acceder a un panel de usuario.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP 8
- MariaDB
- Apache
- Git y GitHub

## Funcionalidades

- Registro de usuarios.
- Validación de campos.
- Verificación de contraseñas.
- Almacenamiento en base de datos.
- Protección de contraseñas mediante hash.
- Inicio y cierre de sesión.
- Dashboard personalizado.
- Diseño responsive.

## Instalación

1. Instalar Apache, PHP y MariaDB.
2. Crear la base de datos `proyecto_login`.
3. Crear la tabla `usuarios`.
4. Copiar `config/conexion.example.php` como `config/conexion.php`.
5. Configurar las credenciales de MariaDB.
6. Colocar el proyecto en `/var/www/html/ProyectoLogin`.
7. Abrir `http://localhost/ProyectoLogin/`.
